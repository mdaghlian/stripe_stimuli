## For colour stimuli 
1) Run findIsoluminance_Blue.m 
    * find bwFitData
2) Run findIsoluminance_Red.m 
    * find redFitData
3) Run makeStimuli.m
    * generate stimuli
4) Run colourProject.m
    * generates also a logfile with onset and duration times for SPM
